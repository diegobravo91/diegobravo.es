Puerta de contradicción / prueba 01 / documento

¿Cuándo un documento conserva una práctica y cuándo empieza a producir la forma en que esa práctica existe para quienes no estuvieron allí?

Una pregunta pública no para recibir opiniones, sino para localizar un caso capaz de volver insuficiente la formulación actual.

01 / Estado

Hipótesis actual

El documento puede mantener una práctica accesible sin ser la práctica.

La hipótesis distingue entre documento como mediación, documento como operación y documento como sustitución. Una fotografía, un contrato, una instrucción, una memoria corporal o un registro pueden relacionarse de maneras distintas con aquello que preservan.

La primera pregunta ya falló

Conservar / sustituir era una oposición demasiado limpia.

La lectura de Philip Auslander obliga a desplazar el problema: para muchos espectadores, el documento no llega después de una performance ya plenamente disponible. Puede ser el principal lugar desde el que esa performance se conoce y se experimenta como obra.

La pregunta cambia, por tanto, de cuándo el documento sustituye a la práctica a qué forma de existencia produce para quienes no estuvieron allí. La sustitución sigue siendo un riesgo posible, pero ya no organiza por sí sola el campo.

02 / Presión

Casos que ya impiden una respuesta simple

Rastro riguroso

Tehching Hsieh

Años vividos bajo reglas extremas sobreviven mediante fotografías, mapas, objetos, contratos y registros. La documentación permite conocer la obra, pero no puede contener la duración vivida que documenta.

DOCUMENTO-DE / PÉRDIDA RECONOCIDA
Transmisión corporal

Tino Sehgal

La obra rechaza reproducción fotográfica y escrita como equivalente suficiente. El conocimiento necesario para volver a realizarla se transmite entre cuerpos, relatos y ensayos.

RESERVA / MEMORIA / TRANSMISIÓN
Documento que actúa

Siegelaub / Projansky

Un contrato no recuerda simplemente una relación artística: puede modificar jurídicamente qué derechos y obligaciones continúan cuando la obra cambia de manos.

03 / Herida

Qué podría hacernos cambiar

Caso A
Una práctica cuya documentación no pueda separarse de aquello que documenta.

No un registro útil, sino un caso donde intentar distinguir acontecimiento y documento destruya la operación.

Caso B
Una ausencia documental que aumente la capacidad de transmisión en vez de reducirla.

Algo más fuerte que simple secreto, prohibición o pérdida: la falta tendría que producir una forma verificable de continuidad.

Caso C
Un documento que conserve perfectamente los datos pero anule la práctica que pretendía preservar.

El caso debería permitir localizar la sustitución, no asumirla por intuición.

Salida
La pregunta está mal formulada.

También cuenta una objeción que demuestre que “documento” y “práctica” no son los términos adecuados para pensar el problema.

Señalar
una fisura.

No buscamos una opinión general sobre documentación. Buscamos un caso, fuente, obra o situación que permita comprobar que alguna parte de la pregunta falla.

Qué falla
La afirmación, distinción o relación que el caso vuelve insuficiente.
Evidencia
Fuente, obra, enlace, documento o experiencia verificable.
Qué cambiaría
Qué parte del Diccionario, Atlas, Libro, práctica o web tendría que reabrirse si la objeción se sostiene.
Fuera de marco
También se admite: “esto no encaja en vuestra pregunta”.

04 / Consecuencia

Qué ocurriría si una fisura supera la criba

Compromiso limitado
No prometemos responder a todo. Una objeción validada puede obligar a una única consecuencia concreta: corregir, reabrir, investigar, probar, retirar o cambiar de versión.La prueba pública de participación sería el cambio producido, no un contador de mensajes.
