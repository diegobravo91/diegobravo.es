# SOCIAL VISUAL SYSTEM — v0.1

Estado: laboratorio interno. No publicar automáticamente.

## Principio
La identidad no debe funcionar como maquillaje del proyecto. Debe hacer visible una lógica ya existente: corte, intervalo, diferencia, duración y retorno.

## Formatos base
Instagram feed: 1080 × 1350 px (4:5).
YouTube miniatura: 1280 × 720 px (16:9).
Stories/Reels: preparar sólo cuando exista material vertical real; no reencuadrar por obligación.

## Sistema
Fondo principal: #eceae4.
Texto: #0d0d0c.
Texto secundario: #6f6b64.
Acento: #ff4a22.

Tipografía: Arial/Helvetica/sans-serif + monospace del sistema.
No depender de fuentes externas ni de licencias tipográficas nuevas.

## Reglas visuales
1. El naranja actúa como corte, no como decoración.
2. Una composición debe soportar zonas vacías.
3. La retícula puede aparecer como huella o tensión, no como plantilla repetida.
4. No hacer todas las piezas “iguales”: conservar familia sin convertirla en marca rígida.
5. Cuando entre fotografía propia, la tipografía debe retirarse si la imagen ya sostiene la operación.
6. No imitar el lenguaje visual de artistas vivos.
7. No usar imágenes ajenas para dar prestigio o densidad.

## Accesibilidad
Añadir alt text manual a cada publicación.
Evitar información esencial sólo por color.
Mantener contraste alto.
No incrustar párrafos largos en una imagen si pueden vivir como caption o web.
