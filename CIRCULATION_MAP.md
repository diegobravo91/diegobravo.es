# CIRCULATION MAP — WEB / INSTAGRAM / YOUTUBE — v0.1

Estado: laboratorio interno.

## Principio
No duplicar contenido entre plataformas. Cada medio debe hacer una operación distinta y devolver al sistema una consecuencia concreta.

## Circuito 01 — Pregunta matriz
WEB
- Punto de origen: /estetica-del-umbral.html
- Núcleo: ¿Qué hace realmente un umbral?

INSTAGRAM
- POST 01: ¿QUÉ HACE UN UMBRAL?
- Función: abrir la pregunta sin explicarla entera.
- Retorno: /estetica-del-umbral.html

YOUTUBE
- Piloto #01: ¿Qué hace un umbral?
- Función: dar duración, diferencias conceptuales y paso a práctica.
- Retornos: Libro + Diccionario + Práctica.

No repetir el mismo texto de la web como voz completa.

## Circuito 02 — Tiempo
WEB
- /notas/el-tiempo-que-no-tenemos.html
- Texto largo y estable.

INSTAGRAM
- POST 03: EL TIEMPO QUE NO TENEMOS.
- Función: señal de entrada.
- No resumir todo el artículo en caption.
- Retorno directo al texto.

YOUTUBE
- Puede aparecer como fragmento leído dentro del piloto #01.
- No crear vídeo separado mientras la lectura no gane algo por la voz/duración.

## Circuito 03 — Diccionario
WEB
- /diccionario.html#umbral
- /diccionario.html#transicion
- /diccionario.html#frontera
- etc.

INSTAGRAM
- Formato: una diferencia por publicación.
- Ejemplo: UMBRAL ≠ TRANSICIÓN.
- Función: precisión, no “definición inspiracional”.

YOUTUBE
- Bloque breve dentro de un ensayo.
- No hacer vídeos enciclopédicos de una entrada si no existe problema propio.

## Circuito 04 — Archivo abierto
WEB
- Atlas: OA-001 / OA-020 / OA-021.
- Función: relación fuerte + procedencia + derechos.

INSTAGRAM
- Sólo si la imagen aporta algo que el texto no puede sustituir.
- Siempre con crédito y retorno a la relación exacta del Atlas.
- Primer test: Muybridge OA-021.
- Estado: HOLD hasta que el lanzamiento contenga imagen/proceso propio.

YOUTUBE
- Material abierto sólo si resulta necesario al argumento.
- No usar archivo histórico como B-roll decorativo.

## Circuito 05 — Práctica propia
WEB
- /practica.html y futuros casos.
- Función: documentación completa.

INSTAGRAM
- Campo / detalle / proceso.
- Función: proximidad y fragmento.

YOUTUBE
- Caso con duración cuando hipótesis, ejecución y consecuencia necesiten tiempo.
- Función: proceso, no tutorial.

## Regla de retorno
Cada publicación debe poder contestar:
1. ¿Qué añade aquí que no está ya en la web?
2. ¿A qué página o caso exacto devuelve?
3. ¿Qué cambiaría si no se publicara?
4. ¿Hay una plataforma más adecuada?

Si ninguna respuesta es clara: no publicar.

## Regla de expansión
No crear una nueva serie por tener material. Crear serie sólo cuando al menos 3 piezas distintas necesiten la misma forma.
