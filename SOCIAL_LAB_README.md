# SOCIAL LAB — diegobravo.es

Rama de desarrollo no publicada en GitHub Pages.

Objetivo:
- probar la arquitectura visual de Instagram y YouTube;
- no inventar cuentas, publicaciones, vídeos ni colaboraciones;
- mantener separada la preparación de la identidad pública real;
- revisar derechos antes de reutilizar material de terceros.

Regla de salida:
1. La web permanece como superficie estable.
2. Instagram sólo se activa cuando existan al menos 3–5 publicaciones reales listas.
3. YouTube sólo se activa cuando exista un primer vídeo con razón de duración propia.
4. Los enlaces a perfiles se añaden a main únicamente cuando sus URLs sean definitivas.
5. Cualquier material ajeno pasa por la matriz: propio → permiso → licencia → dominio público → excepción limitada → enlazar.

El archivo `social-preview.html` es una maqueta, no una identidad publicada.
