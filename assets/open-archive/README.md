# Archivo abierto — manifiesto de procedencia

Este directorio registra materiales de terceros utilizados o preparados para su uso en diegobravo.es.

La regla no es acumular imágenes “libres”, sino conservar para cada activo una procedencia verificable: autor, obra, institución, ficha original, estado de derechos/licencia, fecha de comprobación y operación editorial.

## Regla de mantenimiento

Antes de incorporar un nuevo activo a producción debe existir una ficha equivalente. Para activos CC BY se añadirá la atribución exigida; para licencias con NC, ND o SA se revisará el uso concreto antes de publicar. El dominio público de la obra no sustituye la comprobación de la reproducción concreta.
